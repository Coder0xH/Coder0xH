## 🎯 Featured Projects

### [Drexor](https://github.com/Coder0xH) — Autonomous AI Agent Platform
Full-stack AI agent platform with Web3 authentication. Agents reason autonomously via ReAct + LangGraph, maintain persistent memory with reflection, and interact through real-time SSE streaming.
- **Backend**: Python / FastAPI / SQLAlchemy 2.0 / Redis Streams / APScheduler
- **Frontend**: Next.js 16 / TypeScript / Tailwind CSS 4 / Zustand / CodeMirror
- **Auth**: Wallet login (EVM signatures) / Email+Password / TOTP 2FA / API Keys
- **AI Runtime**: Pluggable skills, memory recall & decay, agent personality ("Soul" system)

### [Dexter-Go](https://github.com/Coder0xH) — Go Microservices Scaffold (DDD)
Production-grade Go microservices mono-repo implementing Domain-Driven Design 4-layer architecture with gRPC inter-service communication.
- **Stack**: Go / Gin / gRPC + Protobuf / PostgreSQL / Redis / JWT
- **Architecture**: Transport → Application → Domain → Infrastructure
- **Features**: Wallet-based auth, WebSocket messaging, blockchain event listeners
- **Tooling**: Google Wire DI / Buf (protobuf) / Docker Compose orchestration

### [Dexter-CLI (dx)](https://github.com/Coder0xH) — macOS Dev Environment Manager
One-command macOS developer setup tool written in Rust. Idempotent bootstrapping, multi-profile identity switching, and AWS credential management.
- **Stack**: Rust / Clap / TOML config
- **Commands**: `dx setup` → `dx sync` → `dx use <profile>` → `dx doctor`
- **Features**: Homebrew orchestration, dotfile sync, iCloud Keychain integration, EC2/ECR helpers
